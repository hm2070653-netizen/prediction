# Notebook

Create/open `customer_churn.ipynb` in VS Code using the Jupyter extension.
The notebook workflow should cover:
1. Load the CSV with pandas.
2. Inspect shape, columns, dtypes, missing values, and churn rate.
3. Plot churn by contract, tenure, and monthly charges.
4. Clean `TotalCharges`, drop `customerID`, and encode `Churn`.
5. Split stratified train/test data and compare models.
